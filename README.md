# Tính Công & Sản Lượng

Ứng dụng iPhone iOS 16+, UIKit thuần. GitHub Actions tạo IPA chưa ký để ký/cài bằng ESign.

## Lưu trữ và chuyển dữ liệu / Data storage and transfer

Ứng dụng lưu dữ liệu tại `Documents/DuLieuTinhCong` gồm:
- `du-lieu-ngay.json`
- `cong-doan-du.json`
- `cai-dat.json`

Có thể mở ứng dụng Tệp trên iPhone, vào **Trên iPhone của tôi > Tính Công > DuLieuTinhCong** và sao chép nguyên thư mục sang máy khác.

The app stores data in `Documents/DuLieuTinhCong`. Copy the entire folder through the Files app to transfer data to another device.
